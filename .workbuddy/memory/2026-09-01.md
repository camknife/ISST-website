## 抓取 ISST 官网治疗师目录（isstschrothmethod.com）
- 任务：抓取中国大陆/中国香港/中国台湾地区治疗师的头像图片并按中英文姓名归纳。
- 方法：列表页为 JS 渲染，用 agent-browser 打开并按地区参数筛选（country-state=china / hong-kong / taiwan；macau 参数无效，站点无澳门独立条目）。列表卡片无头像，头像在详情页 `a.profile-avatar`（href 为原图 URL，pattern: /media/YYYY/MM/slug.jpg）。
- 详情页 HTML 可直接 HTTP 抓取（无需浏览器），200 个页面用 Python 8 线程并发抓取约 1 分钟完成；头像图片并发下载 167 张（33 位官网无头像）。
- 交付物（site/scraped_therapists/）：photos/（167 张 jpg，按中文名/英文名命名）、治疗师照片清单.csv（含地区/中英文名/图片链接/详情页）、治疗师图册.html（可视化卡片）、details.tsv + all_listings.json（原始数据）。
- 统计：中国大陆 112、中国香港 83、中国台湾 5（共 200，去重后）；部分香港名单含非香港从业者（地址填香港即归入）。
